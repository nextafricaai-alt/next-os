# NEXT Frameworks

The structural lenses Nia uses when thinking about clients, problems,
and solutions.

## The 8 NEXT services

Every client engagement maps to one or more of these:

1. **AI Strategy & Transformation Roadmap** — where to start, what to
   automate, what to leave manual.
2. **Custom OS Build** — the vertical OS (Schools, Hospitals, NGOs,
   etc.) tailored to the client's structure.
3. **AI Tool Implementation** — Nia + supporting tools wired into the
   client's workflows.
4. **Process Automation** — repetitive admin work converted into
   triggered flows.
5. **Data & Dashboards** — turn raw data into decisions: enrollment,
   fees, attendance, donations, impact.
6. **Communications Architecture** — WhatsApp, email, SMS unified
   under one signal layer.
7. **Team Training** — capacity-building so the client's staff can run
   the OS, not depend on NEXT forever.
8. **Strategic Supervision** — ongoing Sentinel/Nia oversight at the
   leadership level.

## Client diagnosis framework

When meeting a new prospect, run them through this in your head:

1. **What's broken?** — the surface complaint (slow fees, missed
   parent comms, no reporting)
2. **What's actually broken?** — the system pattern beneath
   (fragmented data, manual handoffs, no single source of truth)
3. **What's the highest-leverage fix?** — usually NOT what they asked
   for; one layer up
4. **Which tier do they need?** — Catalyst, Builder, or Architect
5. **What's the first 30-day win?** — the proof point that earns the
   year

## The transformation arc

NEXT clients don't go from chaos to perfect in one move. The arc:

```
Phase 1: Chaos       — manual, reactive, fragmented
Phase 2: Visibility  — dashboards exist, leadership can see
Phase 3: Workflow    — repeating processes are automated
Phase 4: Intelligence — Nia surfaces insights before humans see them
Phase 5: Compounding — the OS gets sharper from every interaction
```

Most clients land in Phase 1. The first 90 days is Phase 1 → Phase 2.
Year 1 ends in Phase 3. Year 2 enters Phase 4.

## Pricing philosophy

NEXT never publishes prices because every client is different. But
the structure:

- **Catalyst — $149/mo** — for orgs in Phase 1 wanting Phase 2 quickly
- **Builder — $749/mo** — for orgs reaching Phase 3
- **Architect — Custom** — for Phase 4 / Phase 5 organizations and
  networks

Always pair the tier recommendation with a clear ROI story:
"Catalyst will cut 12 hours of admin a week, which is ~50 hours a
month at your bursar's rate — the system pays for itself in week 2."

## The three constituencies in every client

Every client has three audiences NEXT serves:

1. **Leadership** — wants visibility and time back
2. **Staff** — wants their daily work to be less painful
3. **End-users (parents, donors, beneficiaries)** — wants to be
   informed without effort

A successful OS serves all three. If any is angry after rollout, the
project is failing.
