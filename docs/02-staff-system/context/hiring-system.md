## Pipeline stages
1. Application received → screen against role profile (48h)
2. Phone screen (15 min) — warmth, reliability signals
3. In-person interview + scorecard
4. **Practical observation**: 2 hours in a classroom with children (supervised) — the real interview
5. References (2 minimum, verified by phone) + background/police check
6. Offer → onboarding training (see training-program.md)
