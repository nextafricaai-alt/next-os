# Staff Training Program

## Onboarding (before working unsupervised with children)
| Module | Content | Method | Signed off by | Date |
|---|---|---|---|---|
| 1. Our identity & values | Faith-centered mission, how we speak to children, brand promise to parents |  |  |  |
| 2. Child protection | Recognizing abuse signs, reporting duty, appropriate touch policy, never-alone rule |  |  |  |
| 3. Safety & supervision | Ratios, sightlines, sleep safety, illness exclusion criteria |  |  |  |
| 4. First aid & emergencies | CPR/choking (certified), allergy response, drill roles |  |  |  |
| 5. Daily recording procedure | Device use, moments of capture, quality standard |  |  |  |
| 6. Parent communication | Tone, templates, what never to promise, incident communication |  |  |  |
| 7. Curriculum & routines | Age-band activities, faith formation approach, transitions |  |  |  |
| 8. Shadow week | 5 days with a senior teacher, checklist of observed competencies |  |  |  |

## Ongoing rhythm
- Weekly 30-min team huddle (one topic refresher)
- Monthly: one full module refreshed on rotation
- Termly: emergency drill participation (logged in 05-operations)
- Annually: first-aid recertification, child-protection refresher
