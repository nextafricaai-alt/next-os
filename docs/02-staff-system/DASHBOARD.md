# Future Dashboard — Staff System

Center manager's people screen.

- **Today:** who is on shift per room, live child:staff ratio per room (red if over)
- **Recording completeness:** % of daily logs completed by 4pm, by teacher — the accountability metric
- **Training:** each staff member's sign-off checklist %, refreshers due in next 30 days
- **Hiring pipeline:** open roles → applicants → interviews → checks → offers (kanban)
- **Flags:** expired first-aid certs, background checks nearing renewal, review dates due
