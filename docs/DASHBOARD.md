# Future Dashboard — Child Profile

One screen per child, opened by tapping the child's photo.

- **Always-visible banner:** allergies + medical alerts (red), authorized pickup persons
- **Today strip:** arrival time, meals eaten (%), nap duration, mood, photo of the day
- **Growth tab:** height/weight plotted against WHO curves, alerts if trajectory flattens
- **Milestones tab:** age-band map (language / motor / social-emotional) — green achieved, amber emerging, grey not yet; auto-flag if a band is >3 months behind
- **Faith & character tab:** traits observed this term, memorable moments feed
- **Patterns:** nap-length trend, appetite trend, attendance — early-warning signals a teacher would otherwise miss

Data source: the single daily log + periodic assessments. Zero extra data entry.
