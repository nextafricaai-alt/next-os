# Future Dashboard — Parent Experience

Two views:

**Parent-facing app/portal (per family):**
- Today's update card: photo, meals, nap, mood, one specific moment
- Milestone progress ring per child
- Monthly report archive (PDF)
- Message thread with the center; announcements
- Invoices and payment status

**Internal view (center manager):**
- Updates sent vs pending today (should be 100% by 5:30pm)
- Parent read/response rates
- Open parent conversations needing reply >24h
- Satisfaction pulse (termly survey score, NPS trend)
