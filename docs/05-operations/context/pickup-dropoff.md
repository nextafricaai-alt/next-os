# Pickup & Dropoff Procedure

> The most dangerous 30 minutes of the day, twice a day. The system, not familiarity, decides who takes a child home.

## Dropoff
1. Parent signs child in (time, signature/device tap).
2. Staff visual health check (fever signs, injuries from home — note anything in daily log).
3. Parent messages captured in daily log "arrival" section.
4. Child counted into room register.

## Pickup
1. Person requests child → staff checks **authorized pickup list** in master record.
2. Unknown-to-staff person: photo ID against the list. No match = no release, no exceptions, manager called.
3. Parent wants someone new to collect: written/app confirmation from enrolled parent BEFORE release + ID at gate.
4. Sign-out (time, who). Child counted out.
5. Teacher gives 30-second verbal handover (or points to daily update).

## Late pickup
- Grace period: ___ min. After that: call parent → emergency contacts.
- Two staff stay with the child (never one). Late fee per policy: ______
- Uncollected after ___ hours + contacts unreachable → safeguarding procedure.

## Custody & court orders
- Any custody arrangement documented in master record; front desk briefed. When in doubt, manager decides, not the gate.
