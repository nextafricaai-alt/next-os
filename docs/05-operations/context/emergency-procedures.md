## 1. Medical emergency (injury / allergic reaction / seizure)
1. Nearest trained adult treats; second adult secures other children.
2. Severe allergy → child's emergency action plan (health file) → [medication/location].
3. Call [medical number]; call parent; manager rides with child if evacuated.
4. Incident form within 2 hours.

## 2. Fire / evacuation
- Alarm signal: ______  Assembly point: ______
- Roles: [who carries infants] [who takes register & health files] [who sweeps rooms/toilets]
- Headcount at assembly against sign-in register — count twice, two people.

## 3. Missing child
1. Instant headcount all rooms + freeze movement.
2. Search sweep (assigned zones, 3 minutes max).
3. Not found → call police + parents immediately. Never delay hoping.
4. Gate/entry review, incident report severity 4.
