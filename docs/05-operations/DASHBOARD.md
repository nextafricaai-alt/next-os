# Future Dashboard — Operations

The center's "today board" on a wall tablet.

- **In the building now:** children count per room (live from sign-in/out), staff on shift
- **Cleaning:** today's checklist items green/red with signer name and time
- **Kitchen:** today's menu, allergy cross-check confirmed per meal (blocking step), meals served count
- **Pickup window:** expected pickups next hour, any non-routine authorized persons today
- **Drills & maintenance:** next emergency drill due date, open maintenance tickets, low-stock alerts
