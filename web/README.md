# web/ — the deployable NEXT OS site (document root)

Point the `nextos.nextafrica.ai` subdomain's document root here.
- index.html              — NEXT OS dashboard
- school-onboarding.html  — Nia's school onboarding console
- prototypes/             — Schools OS prototype the console rebrands
- vendor/, uploads/       — libraries + logos

Push to main → Hostinger Git auto-deploys this folder. No manual upload.
